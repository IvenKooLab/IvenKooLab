## 🔨 Things I've built

**🧠 Second brain / RAG**

- [loci](https://github.com/IvenKooLab/loci) ![stars](https://img.shields.io/github/stars/IvenKooLab/loci?style=flat-square) — shared memory for AI coding tools: hybrid search, cited Q&A, automatic harness memory discovery and a built-in Web console. Local index, MCP + HTTP · [v0.8.1](https://github.com/IvenKooLab/loci/releases/tag/v0.8.1)
- [loci-dsh](https://github.com/IvenKooLab/loci-dsh) — loci as a sidebar tab in the DeepSeek Harness (dsh) web UI

**🎮 Local AI infrastructure**

- [minimax-h3-turing](https://github.com/IvenKooLab/minimax-h3-turing) ![stars](https://img.shields.io/github/stars/IvenKooLab/minimax-h3-turing?style=flat-square) — field handbook for MiniMax H3 video on a 2080Ti 22G: W4A8 quant, BlockCache, PDD
- [comfy-agent](https://github.com/IvenKooLab/comfy-agent) ![stars](https://img.shields.io/github/stars/IvenKooLab/comfy-agent?style=flat-square) — local-first visual studio for ComfyUI: pure-stdlib Python + vanilla JS, ships as a single 10 MB exe

**🤖 Agent tooling**

- [sub-agent](https://github.com/IvenKooLab/sub-agent) — a 7-phase AGENTS.md that chains skills, tools and subagents through the whole coding flow
- [nacos2-mcp](https://github.com/IvenKooLab/nacos2-mcp) — read-only MCP server for Nacos 2.x, filling the gap in official tooling

**🎨 For fun**

- [desktop-pet](https://github.com/IvenKooLab/desktop-pet) ![stars](https://img.shields.io/github/stars/IvenKooLab/desktop-pet?style=flat-square)— Iven, an independent 3D plush desktop companion for macOS and Windows: animated roaming, mouse interactions and little breaks, with optional local coding-agent status cards for ZCode and DSH. Active Codex desktop sessions are not currently supported
- [violin-schedule](https://github.com/IvenKooLab/violin-schedule) — a cute timetable PWA for violin tutors
